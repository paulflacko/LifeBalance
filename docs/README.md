## Herkunft

Grundlage ist das Konzept „Hantelwoche 2.0“ vom 23.11.2026 und alles, was die Hantelwoche bis dahin konnte (8 Pull Requests). Die Dokumente der ersten Version liegen unverändert in [archiv-hantelwoche/](archiv-hantelwoche/README.md).

## Schreibweise

- Begriffe auf Deutsch, Feldnamen in den Inhaltsdateien ohne Umlaute (`saeule`, `uebung`).
- „Muss“ heißt: gehört in die erste nutzbare Version. „Soll“: bald danach. „Kann“: Idee für später.
