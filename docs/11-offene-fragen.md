# 11 · Offene Fragen

Was vor oder während des Baus entschieden werden sollte. Entschiedenes wandert nach unten.

## Offen

| Frage | Optionen | Vorschlag |
|---|---|---|
| **Name** | „LifeBalance“ ist Arbeitsname | später entscheiden; Titel und Symbol sind leicht zu ändern |
| **Ernährung auf der Startseite** | nur Tageswerte + Eintragen über Plus, oder eigene Karte mit Beispieltag | Tageswerte + Plus, Beispieltag in Plan |
| **Startseite** | feste Reihenfolge oder von Anfang an frei anpassbar | feste Reihenfolge, Ausblenden ab Phase 2, Umsortieren später |
| **Erste Ausbau-Ideen** | siehe [Roadmap](10-roadmap.md#ideen-für-module) | nach Phase 5 wählen |
| **Technik** | reines JavaScript mit ES-Modulen, oder kleines Framework (z. B. Preact, Svelte) mit Build | reines JavaScript, solange es übersichtlich bleibt |
| **Adresse** | neue Pages-Adresse `paulflacko.github.io/LifeBalance/`; Hantelwoche bleibt bis zur Übernahme parallel | so |
| **Sync-Ziel** | Zweig `daten` in diesem öffentlichen Repo (verschlüsselt) oder eigenes privates Repo | eigenes privates Repo |
| **Gewicht und Maße** | optional, Intervall frei | so (Wunsch vom 19.11.) |
