## Training (Vollbild)

```
✕  Kraft A                         [Fertig]
   26. Okt. · seit 12 min
┌ Einstieg · 10 min  3/9 ───────────────┐
│ [Geführt mit Timer]  ☐ Hampelmann …   │
└───────────────────────────────────────┘
┌───────────────────────────────────────┐
│ [Animation]  1 Kreuzheben             │
│              3 × 5                     │
│              Technik · Pause 2–3 min   │
│ Letztes Mal: 80×5, 80×5, 80×5 →       │
│ heute +2,5 kg                          │
│ 1 │ 82,5 kg │ 5 Wdh. │ ✓               │
│ 2 │ 82,5 kg │   Wdh. │ ☐               │
└───────────────────────────────────────┘
▓▓▓▓▓▓▓░░░  PAUSE 1:48  Nächster Satz  [+15 s] [Weiter]
```

**Ablauf eines Satzes:** Gewicht steht schon drin → Satz machen → Wiederholungen eintippen (oder leer lassen = Zielzahl) → ✓ → Pausenleiste läuft unten → Ton und Vibration → nächster Satz.

**a/b-Paare:** Nach 5a startet nur eine kurze Pause mit „Weiter mit 5b“, nach 5b die normale Pause.

**Abbrechen und Fortsetzen:** ✕ speichert den Stand. Auf „Heute“ steht dann „Fortsetzen“.

## Geführter Timer (Vollbild)

```
✕  Kondition + Core-Zirkel     Schritt 12 von 53
           ▬▬▬▬▬▬▬▬▬▬▬▬▬
                LOS
          [  Animation  ]
         Renegade Row
        Runde 2 von 4 · Stufe 1
             0:27
     Danach: Pause · 0:20
   [Zurück]  [Pause]  [Überspringen]
```

- Arbeitsphasen rot beschriftet („Los“), Pausen grün („Locker“).
- In den letzten 3 Sekunden kurze Töne, beim Wechsel ein langer Ton.
- Schritte ohne Zeit (z. B. Aufwärmsätze) warten auf „Weiter“.
- Meditation: animiertes Quadrat für die Box-Atmung (ein, halten, aus, halten), danach Body-Scan in Etappen.
- Am Ende wird der Block auf „Heute“ automatisch abgehakt.

## Woche

Sieben Zeilen Mo–So: Kürzel und Datum, Titel, Zeiten, rechts ein Balken pro Block (rot = erledigt). Vor- und Folgewoche blätterbar. Heute ist markiert.

## Übungen

Filter-Chips (Kraft A, B, C, Einstieg, Zirkel, Mobility, Ersatzübungen), darunter Karten mit Animation, Sätzen (bei Kraft), Technik, Equipment, Muskelgruppe und Link zur Anleitung.

## Ernährung

Ziel-Kacheln → Tageshinweis → Beispieltag zum Abhaken → Schnell-Einträge und freies Formular → Eiweißquellen → Einnahmeplan Supplements → Obergrenzen (aufklappbar).

## Fortschritt

Gewicht eintragen → Empfehlung → Diagramm (Punkte = Messungen, Linie = Wochenschnitt) → Wochentabelle → alle Messungen (aufklappbar) → Bestwerte Grundübungen → Trainingsverlauf.

## Einstellungen

Start der Trainingswoche 1, kcal- und Eiweißziel, Renegade-Row-Stufe, Schalter (Klimmzugstange, Zirkel 45/15, Eisen, Zink), Sicherung speichern und laden, alle Daten löschen mit zweitem Klick zur Bestätigung.
