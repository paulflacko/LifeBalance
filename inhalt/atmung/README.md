## Phasen im Rhythmus

- `prep`: Bereit machen
- `in`: Einatmen
- `top`: Nachatmen
- `hold`: Halten
- `out`: Ausatmen
- `rest`: Leer halten
- `retain`: Luft anhalten
- `free`: Frei atmen
