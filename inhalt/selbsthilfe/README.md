# Kopf und Gefühle: Selbsthilfe-Übungen

24 Übungen, alle in eigenen Worten beschrieben. Quellen siehe [LIZENZEN.md](../../LIZENZEN.md).

> Selbsthilfe, keine Therapie. Die Übungen stammen aus gut untersuchten Therapieformen und helfen vielen Menschen im Alltag. Sie ersetzen aber keine Behandlung. Wenn es dir über Wochen schlecht geht, sprich mit deiner Hausärztin oder einem Psychotherapeuten (Termin über 116 117). In einer Krise sofort Hilfe holen: Telefonseelsorge 0800 111 0 111 oder 0800 111 0 222 (kostenlos, rund um die Uhr), Notruf 112.
