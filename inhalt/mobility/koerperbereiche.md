# Mobility nach Gefühl: Körperbereiche

Man wählt Bereiche (Gewicht 1 oder 2), ein Gefühl und eine Dauer. Die App stellt daraus einen Ablauf zusammen (Logik in [docs/06-logik.md](../../docs/06-logik.md#mobility-nach-gefühl)).

## Gefühl

| Gefühl | Wirkung | Haltezeit-Faktor |
|---|---|---|
| Steif | Mehr Bewegung, kürzer halten | 0.85 |
| Verspannt | Länger halten, ruhig ausatmen · Bei jedem Ausatmen ein Stück loslassen. | 1.3 |
| Müde oder gestresst | Sanft, viel am Boden, Entspannung am Ende | 1.15 |
| Ganz gut | Ausgewogen | 1 |

| Stichwort in „Muskeln“ | Belastete Bereiche (Gewicht) |

| unterer rücken | Unterer Rücken 1 |
| nacken, trapez | Nacken 1, Schultern 0.4 |
| brust | Schultern 1, Oberer Rücken 0.4 |

| trizeps, bizeps, arme, unterarm, griff | Schultern 0.4 |
| rücken, lat (nicht „unterer“) | Oberer Rücken 1, Unterer Rücken 0.4, Schultern 0.3 |
| po | Po 1, Hüfte 0.4 |
